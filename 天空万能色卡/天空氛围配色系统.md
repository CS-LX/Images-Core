# 天空万能色卡：可复用天空氛围配色系统

本文件整理自 `sky-atmosphere-palette` 技能中的通用内容，剔除了具体引擎实现部分，可用于插画、概念设计、材质设计、游戏美术、影视分镜、AI 绘图提示词和任意渲染管线的天空氛围设定。

## 设计依据

天空颜色主要由大气散射与色温变化决定：

| 现象 | 物理机制 | 视觉结果 |
|------|---------|---------|
| 蓝天 | 瑞利散射，短波蓝光散射更强 | 天顶更深蓝，地平线更浅蓝 |
| 日出/日落红 | 光线穿过更厚大气层，蓝光被散射殆尽 | 地平线呈橙红、金色 |
| 白天地平线偏白 | 多次散射叠加，各波长趋于均匀 | 地平线饱和度下降 |
| 黄昏紫 | 剩余红光与高层蓝光散射叠加 | 天顶出现蓝紫色调 |
| 夜空深蓝 | 太阳光仅通过高层大气间接散射 | 深邃钴蓝、靛蓝 |

色温参考轴：

```text
2000K ──── 3000K ──── 4000K ──── 5500K ──── 7000K ──── 10000K+
 橙红      暖金       暖白       中性白      冷蓝白      深蓝
日出/落    黄金时段    早晨阳光    正午       阴天/阴影    蓝调时刻
```

## 天气修正规则

在基础时段色板上叠加天气修正，而不是重做整套颜色。

| 天气 | 饱和度修正 | 明度修正 | 色相偏移 | 对比度 | 雾浓度 |
|------|-----------|---------|---------|--------|--------|
| 晴天 | ×1.0 | ×1.0 | 0° | 正常 | 低 |
| 多云 | ×0.5 | ×0.85 | 0° | 降低 | 中 |
| 阴天 | ×0.2 | ×0.7 | +5° 偏暖灰 | 很低 | 高 |
| 雨天 | ×0.15 | ×0.6 | +3° 偏青灰 | 极低 | 极高 |
| 雪天 | ×0.3 | ×1.1 | -5° 偏冷蓝 | 低 | 高，白雾 |

正午 + 阴天示例：

| 位置 | 晴天 | 阴天修正后 |
|------|------|-------------|
| 天顶 | `#4a90d9` | `#8a9aa8` |
| 中天 | `#87ceeb` | `#a8b8c4` |
| 地平线 | `#d2e8f5` | `#c8cdd2` |
| 方向光 | `#fffaf0` | `#d8dce0` |
| 环境光 | `#a8c8e8` | `#8898a4` |

阴天关键：所有颜色向中性灰蓝 `rgb(168, 176, 184)` 靠拢，方向光强度降至晴天的 30%-50%。

## 使用检查清单

- [ ] 天顶色饱和度通常高于中天和地平线，符合垂直饱和度递减规律。
- [ ] 日出 / 日落时地平线偏暖，天顶仍属于蓝色系。
- [ ] 方向光颜色与地平线色色相接近。
- [ ] 雾色或远景融色优先取地平线色。
- [ ] 环境光色相应介于天顶色与地平线色之间。
- [ ] 夜间方向光强度低于 0.1，正午方向光强度高于 1.5。
- [ ] 天气修正后不出现负值颜色或过度脏灰。
- [ ] 相邻时段过渡应平滑，避免色相跳变。

## 配套资产

已将可复用图片资产整理到：

```text
sky-atmosphere-palette-assets/
```

资产包括：

- `strip_01_deep_night.png` 到 `strip_10_dusk.png`：10 个时段的竖向天空渐变条。
- `spectrum_full_day.png`：全天 10 时段并排色谱。
- `lut_sky_10periods.png`：天空渐变 LUT。
- `lut_sun_color.png`：方向光颜色 LUT。
- `lut_ambient_color.png`：环境光颜色 LUT。
- `ref_blue_hour.jpg`、`ref_golden_hour.jpg`、`ref_sunset.jpg`：视觉参考图。

LUT 通用采样思路：

```text
天空 LUT：
  x = altitude_normalized * 255
  y = period_index * row_stride + row_offset

方向光 / 环境光 LUT：
  x = day_time_normalized * 255
```

其中：

- `altitude_normalized = 0` 表示天顶。
- `altitude_normalized = 1` 表示地平线。
- `day_time_normalized = 0` 表示深夜起点。
- `day_time_normalized = 1` 表示暮光终点。
